# Owlet Dashboard 0.1.13

## What’s new

- **Baby profiles from Owlet.** Import the baby’s name, birth date, and gender-derived pronouns. Accounts with multiple profiles get a picker. Existing manual name, birth-date, and she/he/they choices stay in control; refreshing does not overwrite them.
- **History backfill.** Fill collection gaps using Owlet’s historical services. Backfill is on by default and can be turned off under **Settings → Device → Fill gaps from Owlet history** without deleting existing history or stopping live collection. Status shows the last check and whether history was imported, already covered, unavailable, or could not be fetched.
- **Finer Rhythms views.** Choose 5-, 10-, 15-, or 30-minute resolution.
- **Clearer sign-in errors.** Authentication failures now provide more useful diagnostics without exposing credentials or upstream response details.

## Fixes

- Rapid Rhythms resolution changes no longer let an older request replace the latest selection. Failed requests keep the existing charts and allow retrying.
- Backfill uses the selected child, checks that selection again before writing, and recovers longer offline gaps up to the configured limit. Empty or failed responses do not incorrectly mark an initial import complete.
- Live readings take precedence over historical averages, including readings that arrive during or after an import. Turning backfill off cancels pending work.
- Switching accounts keeps names, pronouns, charts, event creation, device details, and chart popups scoped to the selected account.

## Updating

**Windows:** use **Instance → Check for updates…**, or download **Owlet-Dashboard-0.1.13-windows-setup.exe** from the assets below. The installer is signed, and the app verifies it using the published updater manifest. Existing settings and collected history are retained.

**Docker / Unraid:** pull `ghcr.io/pbozzay/owlet-dashboard:latest` and recreate the container with the existing `/data` volume. On Unraid, choose **Check for Updates**, then **Update**. Docker Hub images are also published when that registry is configured.

## Backfill notes

Historical vitals are **10-minute averages**, even when displayed on a finer grid; they cannot reproduce short events visible in live readings. Backfill availability depends on what Owlet returns for the selected profile. The default initial window is 90 days, not a guarantee that Owlet retains that much history.

Set `HISTORY_BACKFILL=false` and restart the server to disable automatic imports globally. The per-account control keeps previously imported data. If you change children after importing, remove that account’s old backfilled rows before importing the new profile; live readings are retained.

Local tests and browser checks passed, including synthetic imports and repeated runs. Real-account authentication and profile import were verified, but the tested history requests returned empty results; a nonempty real-history import has not yet been independently confirmed.

Keep only one Dashboard collector connected to an Owlet login at a time. A second collector can invalidate the first collector’s session. A desktop app connected as a viewer does not run a second collector.

This is an unofficial retrospective dashboard, not a medical monitor or a replacement for the Owlet app and base station.
