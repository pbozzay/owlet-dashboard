# Owlet Dashboard 0.1.14

## History improvements

- The default initial history window increases from 90 to **365 days**, helping recover older readings when recent history is empty. Explicit `HISTORY_BACKFILL_DAYS` settings still apply. Availability depends on what Owlet retains for your selected child.
- Increasing the configured lookback scans the larger window once. Later runs remember the largest completed lookback, so lowering and restoring the setting or running a short manual refresh does not unnecessarily repeat the full import.
- Sleep requests use the account's named timezone. With Auto selected, supported whole-hour device offsets use an equivalent fixed-offset zone; fractional-hour or invalid offsets fall back to UTC. Choose a named timezone for daylight-saving-aware handling.
- Buckets with missing, nonfinite, or nonpositive heart-rate/oxygen averages are skipped and their count is logged. Missing values on the Data chart appear as gaps instead of false zeros.

## Data safety and validation

Live readings still take priority over historical averages. Imports remain scoped to the selected account and child, and can be disabled without stopping live collection or deleting existing history. Historical vitals remain 10-minute averages, even when displayed on a finer grid.

A real global-account import was verified on an isolated database copy: repeated imports created no duplicates and preserved every live reading. EU routing is covered by automated tests. The combined Python and JavaScript regression suite passes, including lookback tracking, timezone fallback, missing chart values, and concurrent live-reading safeguards.

## Updating

**Windows:** use **Instance → Check for updates…**, or download **Owlet-Dashboard-0.1.14-windows-setup.exe** below. The in-app updater verifies the installer using its update signature. Existing settings and collected history are retained.

**Docker / Unraid:** pull `ghcr.io/pbozzay/owlet-dashboard:latest` and recreate the container using the existing `/data` volume.

Keep only one Dashboard collector connected to an Owlet login at a time. This is an unofficial retrospective dashboard, not a medical monitor or a replacement for the Owlet app and base station.
